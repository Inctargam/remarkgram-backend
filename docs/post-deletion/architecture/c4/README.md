# Архитектурные диаграммы C4

Диаграммы сгруппированы по уровням C4 и названы по описываемым возможностям системы:

```text
docs/architecture/c4/<level>/<capability>.md
```

Для каталогов и файлов используется `kebab-case` в нижнем регистре. Исходный код диаграммы хранится
в блоке Mermaid рядом с пояснениями. Благодаря этому диаграмма версионируется вместе с документацией
и поддерживает интерактивный предпросмотр во время редактирования.

## Уровни

- `system-context` — пользователи, система Remarkgram и внешние системы. На этом уровне не показываются
  внутренние сервисы, базы данных, очереди и детали реализации.
- `container` — развёртываемые приложения и хранилища данных внутри Remarkgram.
- `component` — компоненты внутри выбранного контейнера.

Для удаления поста задокументированы System Context, Container и Component-уровень трёх участвующих
приложений. User Accounts не получает вызовов в этом сценарии, поэтому отдельная компонентная
диаграмма для него не создаётся.

## Редактирование с интерактивным предпросмотром

Откройте Markdown-файл диаграммы в редакторе с поддержкой предпросмотра Mermaid либо скопируйте
его блок `mermaid` в [Mermaid Live Editor](https://mermaid.live/). Markdown-файл в репозитории остаётся
единственным источником истины.
